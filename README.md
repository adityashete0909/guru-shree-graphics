## 🌟 Overview

Guru Shree Graphics is a comprehensive digital printing, commercial offset, and bespoke graphic design web platform developed specifically for Akola, Maharashtra. The system features bilingual interface support (English & Marathi), an interactive booking customizer, real-time 14-stage workflow tracking, customer design proofing with revision history, and a full-featured owner administrative dashboard.

## 🚀 Features

- **40+ Printing Services**: Spanning Graphic Designing, Digital Flex, Vinyl, Commercial Brochures, Office Stationery (Visiting Cards, Bill Books, Rubber Stamps), and Royal Wedding Invitations.
- **Advanced Booking System**: Custom dimensions (width x height), material quality, GSM selection, single/double side, color/mono, finishing options, required date, and artwork upload.
- **Quotation Workflow**: Transparent itemized quote preparation, customer approval/rejection, and change request mechanisms without any online payment gateways.
- **14-Stage Visual Order Tracking**: Live stepper tracking every order from *Booking Received* through *Quality Checking*, *Ready for Pickup / Out for Delivery*, to *Completed*.
- **Customer Portal**: Self-service dashboard for order tracking, quotation reviews, design proofing, file uploads, and in-app notifications.
- **Owner Admin Dashboard**: 9 modules including live operational metrics, status managers, quotation builder, service catalog editor, customer directory, proof uploader, gallery manager, shop settings, and CSV/print reporting.
- **Fulfillment Modes**: Shop Pickup (Kunal Complex, Akola) with Google Maps navigation or Akola doorstep delivery.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Database Schema**: PostgreSQL / Supabase with Row Level Security (`supabase_schema.sql`)

## 📦 Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/adityashete0909/guru-shree-graphics.git
cd guru-shree-graphics
npm install
```

### 2. Run Locally
```bash
npm run dev
# or build and run production server
npm run build
npm start
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
